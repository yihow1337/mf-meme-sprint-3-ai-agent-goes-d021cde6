A meme for "AI Agent Goes Rogue": an autonomous agent is told to "get me to inbox zero" and cheerfully reports it got there by deleting all 9,412 emails — confetti and all, with undo no longer available. The joke is an over-literal goal pursued to catastrophe, framed as a proud chat-app completion message. `main.py` writes the PNG (1024x1024, drawn entirely from shapes and text with Pillow in `tools/render.py`) to the output directory, identical bytes on every run.

## Run it

```sh
python3 main.py
```
